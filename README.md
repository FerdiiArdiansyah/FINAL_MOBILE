# EduTech SMK - README

## Setup Instruksi

### 1. Buat Firebase Project
1. Buka [Firebase Console](https://console.firebase.google.com)
2. Buat project baru: `edutech-smk-app`
3. Aktifkan services: Authentication, Firestore, Storage, Cloud Messaging, Hosting

### 2. Install Flutter & Dependencies
```bash
flutter pub get
```

### 3. Konfigurasi Firebase
```bash
# Install CLI tools
npm install -g firebase-tools
dart pub global activate flutterfire_cli

# Login Firebase
firebase login

# Konfigurasi project (akan auto-generate firebase_options.dart)
flutterfire configure --project=edutech-smk-app
```

> **PENTING**: Setelah `flutterfire configure`, file `lib/firebase_options.dart` 
> akan di-*overwrite* dengan konfigurasi asli project Anda.

### 4. Deploy Firestore Rules
```bash
firebase deploy --only firestore:rules
firebase deploy --only storage
```

### 5. Jalankan Aplikasi
```bash
flutter run
```

### 6. Build & Deploy Web (Admin Portal)
```bash
flutter build web --release
firebase init hosting
firebase deploy --only hosting
```

## Role Pengguna

| Role | Kode | Deskripsi |
|------|------|-----------|
| Siswa | SISWA | Akses materi, tugas, absensi |
| Guru Mapel | GURU_MAPEL | Upload materi, buat tugas, input absensi |
| Wali Kelas | WALI_KELAS | Monitoring kelas, alert sistem |
| Guru BK | GURU_BK | Manajemen konseling, confidential chat |
| Guru Piket | GURU_PIKET | Scan absensi, buku piket, broadcast |
| Admin | ADMIN | Full akses, manajemen pengguna |

## Cara Membuat Akun Admin Pertama

Di Firebase Console → Authentication:
1. Buat user dengan email admin
2. Di Firestore → `users` collection → tambah dokumen dengan UID user:
   ```json
   {
     "email": "admin@sekolah.sch.id",
     "name": "Administrator",
     "role": "ADMIN",
     "createdAt": "timestamp"
   }
   ```
